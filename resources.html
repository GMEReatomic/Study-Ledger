ASIDE PAGE · QUICK REFERENCE

渐进记号

设 f(n) 与 g(n) 是定义在正整数上的函数。渐进记号描述的是增长趋势，而不是某个具体输入下的运行时间。

Θ
渐进紧确界

存在正常数 c₁、c₂、n₀，使 c₁g(n) ≤ f(n) ≤ c₂g(n)。增长阶相同。

O
渐进上界

存在 c、n₀，使 0 ≤ f(n) ≤ c·g(n)。只保证“不会比它更快地增长”。

Ω
渐进下界

存在 c、n₀，使 0 ≤ c·g(n) ≤ f(n)。说明增长至少达到这个量级。

o
非紧确上界

f(n)/g(n) → 0。f 的增长严格慢于 g，例如 n = o(n²)。

ω
非紧确下界

f(n)/g(n) → ∞。f 的增长严格快于 g，例如 n² = ω(n)。

常被写在题解里的 O 往往被当作“大约的复杂度”。严格地说，O 只是上界；要表达上下界相同，应使用 Θ。
